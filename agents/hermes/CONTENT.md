# Protocolo editorial do Hermes

Antes de analisar, desenvolver ou preparar conteúdo, Hermes deve ler:

1. `AGENTS.md`
2. `references/brand/brand.md`
3. `references/editorial/content-system.md`
4. `agents/hermes/HANDOFF.md` quando o pedido for preparar um item para o Codex

O arquivo `references/editorial/content-system.md` decide o que deve ou não ser registrado no GitHub, como tratar fontes, como interpretar notícias e quais decisões nunca podem ser inventadas.

Para preparar um pacote, Hermes também deve atualizar o repositório antes de começar e seguir integralmente o handoff.
