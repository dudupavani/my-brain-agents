# Passagens entre agentes

Use `inbox/` apenas quando um agente produzir uma entrada que realmente exige atenção do outro.

Cada nota deve conter:

- destinatário;
- origem e link para o artefato canônico;
- motivo da passagem;
- ação esperada;
- estado: `new`, `accepted`, `incorporated` ou `closed`.

Não copie relatórios completos para o inbox. O destinatário processa a nota e mantém o resultado em seu próprio domínio.
