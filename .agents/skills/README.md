# Skills compartilhadas do projeto

As skills desta pasta são procedimentos portáteis entre Hermes, Codex, Claude e outros runtimes compatíveis. Uma skill representa uma capacidade reutilizável; não é agente, memória factual ou histórico de execução.

No Hermes, estas skills são descobertas como skills locais do projeto quando a sessão roda dentro deste repositório. Cada profile precisa confiar o projeto uma vez para carregá-las.

- Atualizações substituem o conteúdo anterior no mesmo caminho.
- Não criar versões numeradas ou cópias paralelas.
- Só registrar procedimentos recorrentes, claros e úteis.
- Não incluir tokens, credenciais, arquivos `.env` ou dados sensíveis.
- Toda skill deve indicar seu escopo e não assumir autoridade sobre outro domínio sem registrar essa dependência.
- Skills privadas, pessoais ou ainda experimentais permanecem no profile do Hermes até haver motivo para promoção.
