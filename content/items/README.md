# Pacotes de conteúdo

Crie uma pasta por conteúdo com ID estável e legível, por exemplo `20260907-como-criar-um-sistema-de-conteudo`.

Comece pelos arquivos de `content/templates/`. Um pacote só pode receber `ready_for_design` quando `brief.md` e `carousel.md` estiverem completos. Antes da produção visual, a skill cria `visual.md` a partir do modelo correspondente.

O estado não representa uma troca obrigatória de agente. Quando Eduardo pedir um carrossel, o texto dos slides é feito pela skill `motor-de-carrossel`.

Pacotes antigos são experimentos preservados e não definem automaticamente regras para novos trabalhos.
