# Pacotes de conteúdo

Crie uma pasta por conteúdo com ID estável e legível, por exemplo `20260907-como-criar-um-sistema-de-conteudo`.

Comece pelos arquivos de `content/templates/`. Um pacote só pode receber `ready_for_design` quando `brief.md` e `carousel.md` estiverem completos.

O estado não representa uma troca obrigatória de agente. O mesmo profile `personal-content` pode continuar para a capacidade visual quando Eduardo pedir explicitamente essa produção.

Pacotes antigos são experimentos preservados e não definem automaticamente regras para novos trabalhos.
