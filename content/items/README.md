# Pacotes de conteúdo

Crie uma pasta por conteúdo com um ID estável e legível, por exemplo `20260907-como-criar-um-sistema-de-conteudo`.

Comece copiando os arquivos de `content/templates/`. Um pacote só pode receber `status: ready_for_design` quando `brief.md` e `carousel.md` estiverem completos.
