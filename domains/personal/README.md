# Domínio pessoal

Este é o espaço para materiais pessoais gerais que não pertencem a um domínio especializado, como produtos ou Instagram.

Antes de criar subpastas, confirme que existe uma responsabilidade clara e recorrente. O agente deve preferir nomes que expliquem o tipo de memória guardada e registrar decisões importantes em arquivos pequenos e rastreáveis.
