# Reels do Pomake

Conteúdo orgânico do Pomake, produzido somente como [Reel com a Lívia](../editorial-strategy/reel-livia.md) pela skill [`pomake-reels`](../../../../.agents/skills/pomake-reels/SKILL.md).

**Só entra aqui o que Eduardo aprovou.** O Reel é escrito como rascunho fora do repositório e só é gravado nesta pasta depois da aprovação dele. Rascunhos rejeitados são descartados. (Decisão de Eduardo em 2026-10-10.)

Cada arquivo é nomeado `AAAA-MM-DD-<assunto>.md`. O cabeçalho registra estado, pauta, território e técnicas de gancho; o corpo traz o pacote de texto (roteiro da Lívia, legenda e texto do criativo). Estados nesta pasta:

- **aprovado:** aprovado por Eduardo;
- **publicado:** publicado no perfil.

Todos os Reels desta pasta são referência de qualidade para os próximos.
