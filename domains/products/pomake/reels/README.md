# Reels do Pomake

Conteúdo orgânico do Pomake, produzido somente como Reel pela skill [`pomake-reels`](../../../../.agents/skills/pomake-reels/SKILL.md).

**Só entra aqui o que Eduardo aprovou.** O Reel é escrito como rascunho fora do repositório e só é gravado nesta pasta depois da aprovação dele. Rascunhos rejeitados são descartados. (Decisão de Eduardo em 2026-10-10.)

Cada arquivo é nomeado `AAAA-MM-DD-<assunto>.md`. O cabeçalho registra estado, pauta, **recorte escolhido** e território; o corpo traz o pacote de texto (roteiro, legenda e texto do criativo). Estados nesta pasta:

- **aprovado:** aprovado por Eduardo;
- **publicado:** publicado no perfil.

Os Reels desta pasta registram o que foi aprovado e ajudam a escolher um recorte novo quando a mesma pauta for usada outra vez. Não trate a redação deles como modelo de fala natural: a compreensão do público precisa ser observada nos vídeos gravados.

`rejeicoes.md` guarda somente o motivo de cada rejeição, nas palavras de Eduardo, nunca o texto rejeitado. O motor lê esse arquivo para não repetir os mesmos erros. Ele só existe depois da primeira rejeição com motivo.
