## Como registrar uma referência

- Use apenas referências que você tem autorização para guardar e consultar.
- Descreva princípios observáveis: hierarquia, contraste, composição, ritmo, tipografia, cor ou tratamento de imagem.
- Evite instruções vagas como “faça igual”. O objetivo é orientar uma criação original.
